# FastAPI 에서 HTML로 알림 보내기

# [흐름]

- HTML -> SSE 연결 -> FastAPI 연결 -> 이벤트 대기 상태
- 이상징후 발생 -> Queue 저장 -> SSE 전송 -> EventSource 수신 -> HTML -> 알림 표시

# SSE란?

- Server-Send Events
- 서버가 웹 브라우저에 실시간으로 데이터를 전달하기 위한 통신 방식

# SEE 특징

- 통신방향 : 서버 -> 클라이언트 (단방향)
- 연결 : HTTP 연결을 계속 유지
- 브라우저 API : EventSource
- 데이터 수신 : message 이벤트
- 재연결 : 연결이 끊어지면 브라우저가 기본적으로 재연결 시도
- 용도 : 알림, 상태 변화, 로그, 진행 상황 등

# SSE 방식

- 브라우저가 처음에 FastAPI서버와 연결을 한 번 생성하고 그 연결을 유지하면서 서버가 보내는 데이터를 계속 받는 방식

[SSE 방식]

브라우저 --------------- FastAPI
│ -------------------------│
│──── SSE 연결 요청 ──────→│
│ -------------------------│
│ 연결을 계속 유지 │
│ -------------------------│
│ │ ← 이상징후 발생
│←──── 알림 데이터 ────────│
│ -------------------------│
│ 연결 계속 유지 │
│ -------------------------│
│←──── 새로운 데이터 ──────│
│ -------------------------│
