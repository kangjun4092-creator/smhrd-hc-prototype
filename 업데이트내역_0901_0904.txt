  1) AI 자세 판정 및 운동 (누르면 바로 체험 시작)
  2) 실시간 크루대전 (누르면 로그인 없이 실제 홈크루 가입요청 목록을 볼 수 있는
     "홈크루 둘러보기" 화면으로 이동 — 가입요청/크루생성 버튼만 회원가입으로 유도)

  앉은자세 실루엣+크루대전 스코어보드, 실제 히스토리 화면 캡처

[홈크루]
- 미션 카테고리 폐지 → 운동 탭에서 개인 일일 미션으로 통합
- 크루 생성/가입 서브탭 제거, "우리동네 크루 가입하기"를 기본 화면으로 변경
- 크루 컨셉 태그 5종(#다이어트 #크루랭킹 #친목 #근육강화 #건강유지) 추가 — 생성 시 필수 선택,
  가입 목록·크루 내부에 노출
- 크루 가입 카드 개편: 누적점수/크루장 스탯박스 카드 삭제 → 크루장 이름은 일반 텍스트로,
  버튼명 "가입하기"→"가입요청하기", 시/구/동 옆에 컨셉 필터(선택 사항) 추가
- 크루채팅 탭 신규 추가 (메시지 전송 시 크루원이 랜덤 문구로 자동 응답하는 시뮬레이션)
- "5vs5 크루대전" 신규 기능:
  - 실제 웹캠 스쿼트 판정으로 내 점수를, 팀원 4명·상대팀 5명은 자동 시뮬레이션으로 점수 진행
  - 정확도 등급별 점수제(PERFECT 2점 / GREAT·GOOD 1점 / MISS 0점), 목표 점수 선도달 시 승리
  - "크루대전파티맺기": 데려갈 크루원을 체크박스로 선택해 초대 → 10초 내 자동 수락 시뮬레이션
    → 전원 파티 완료돼야 "대전 시작" 버튼 활성화
  - 결과 팝업 개편: 우리팀/상대팀 전원(닉네임+캐릭터)을 점수순으로 나열, 각 팀 1등은
    MVP 배지+전용 폰트로 표시, 전체 참가자 PERFECT/GREAT/MISS 판정 비율 표시
- 크루메인 카드 정리: "팀미션 진행률" 카드 삭제, "크루 레벨·누적 경험치" 카드 안에
  레벨업까지 필요한 경험치(예: 1,400/2,000) 진행바 추가

[운동]

  시작되면 스쿼트 최저점(앉은) 자세 고스트로 자동 전환
- "리플레이 분석"을 별도 단계에서 웹캠 촬영 화면의 결과 팝업으로 통합 (촬영 종료 즉시
  팝업으로 반복별 판정·내 영상 비교가 뜨고, 저장/재촬영을 그 자리에서 선택)
- 레벨별 하루 가능한 운동세트(세션) 한도 추가: 기본 3세트, 5레벨마다 +1, 포인트 상점
  "세트 추가권"(200P, +3세트) 구매로 확장 가능 — 한도 소진 시 새 세션 시작 차단
